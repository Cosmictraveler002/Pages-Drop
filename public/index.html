    Create your connection token

    A secure token lets this dashboard upload your static files to Cloudflare Pages.

    Open Cloudflare to create token ↗
    Exact steps to follow:
    1. Click Create Token
    2. Click Get started next to Custom Token
    3. Name it: Pages Dashboard
    4. Permissions: Account > Cloudflare Pages > Edit, Account > Account Settings > Read
    5. Account Resources: Include > All accounts
    6. Click Continue to summary > Create Token > Copy
    ⚠️ Copy it now: Cloudflare only shows it once. If you lose it, create a new one.
    ⛔ Safety warning: Do NOT use Global API Key. It is unsafe. Use API Token only.
    [Cloudflare API Tokens Screen]
